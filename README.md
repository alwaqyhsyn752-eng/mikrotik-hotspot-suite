# MikroTik Hotspot & Voucher Suite

نظام متكامل لإدارة شبكات الميكروتيك (Hotspot + Voucher).

## المكونات
- 20 قالب تسجيل دخول futuristic (Crystal Cyan)
- صفحة استعلام عن الكرت
- خدمة سلفني
- مولّد كروت مع QR
- محرر بصري No-Code

## تشغيل محلي
python -m http.server 8000 --directory web
